## 📌 Project Overview
This repository contains the end-to-end implementation of **Task 3: Data Visualization** for the **CodeAlpha Data Analytics Virtual Internship**.

Using the global Netflix titles dataset (7,780+ records), this project visualizes streaming catalog dynamics, growth trends over time, geographic content concentration, and audience maturity segmentation.

---

## 🎯 Task Criteria Addressed
- [x] **Transform Raw Data into Visuals**: Cleaned datetime attributes and engineered geographic aggregations.
- [x] **Compositional Donut Chart**: Highlighted 69.1% Movies vs. 30.9% TV Shows catalog breakdown.
- [x] **Time-Series Analysis**: Line plot tracking explosive catalog expansion peaking in 2019 (~1,500 titles).
- [x] **Geographic Ranking**: Horizontal bar chart identifying the top producing countries (US, India, UK).
- [x] **Categorical Maturity Comparison**: Grouped bar chart comparing TV-MA, TV-14, and Family demographics.
- [x] **Executive 4-in-1 Dashboard**: Unified multi-panel dashboard synthesizing the complete Netflix data story.

---

## 📊 Key Insights
1. **Catalog Domination**: Movies represent over two-thirds (69.1%) of Netflix's global library.
2. **Content Explosion**: Catalog additions grew exponentially between 2016 and 2019.
3. **Geographic Concentration**: The United States (2,883 titles) and India (956 titles) lead global production.
4. **Adult Audience Focus**: Mature audience ratings (TV-MA) form the single largest content demographic.
